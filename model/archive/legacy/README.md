# Relatively less important model code

This folder contains historical, exploratory, or currently non-primary model variants. They were moved here without deletion so earlier experiments remain reproducible.

The main `model/` directory keeps the selected Baseline, EDSR, E3, E6, GSNO, NoGS, ScatterGS, ScaleConsistent and LR-primitive transport entry points. Imports and `Train_Cave.py` registrations were updated after the move.

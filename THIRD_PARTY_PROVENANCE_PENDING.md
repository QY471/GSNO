# Third-party provenance pending

The following components are present for internal staging but require a license/provenance audit before any public release:

- `ops/msi_conditioned_gaussian_renderer/`;
- `extensions/`;
- `submodules/diff-srgaussian-rasterization/`;
- Python and CUDA package dependencies listed in `requirements.txt`;
- any code copied from external baseline repositories.

For each component, the release audit must record the upstream repository, commit SHA, license text, modifications made by GSFusion, and whether redistribution is permitted. External baseline source is intentionally not included in this staging copy.

Until this file is resolved, do not publish the staging tree.
